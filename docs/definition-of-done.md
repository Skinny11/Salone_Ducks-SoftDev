# Definition of Done (DoD) - Salone Ducks

A user story is complete when ALL of the following criteria are met:

---

## Code Quality
- [ ] Code is committed to the GitHub repository
- [ ] Code follows consistent naming and formatting
- [ ] No compiler warnings or errors
- [ ] HTML is valid and semantic
- [ ] CSS is responsive (320px - 1920px)

## Testing
- [ ] All acceptance criteria (Given-When-Then) are passing
- [ ] No critical bugs remain
- [ ] Manual testing on:
  - [ ] Desktop Chrome
  - [ ] Desktop Firefox
  - [ ] Mobile Safari
  - [ ] Mobile Chrome

## Documentation
- [ ] User story is updated with completion notes
- [ ] Code comments are clear for non-obvious logic

## Performance
- [ ] Pages load within 3 seconds on 4G
- [ ] Form submissions complete within 5 seconds

## User Experience
- [ ] Error messages are clear and helpful
- [ ] Form validation works correctly
- [ ] No broken links or missing images

---

## Definition of Ready (DoR)
- [ ] User story has clear acceptance criteria
- [ ] User story is estimated and prioritised
- [ ] Dependencies are identified

---

## Quality Gates

| Gate | Criteria |
|------|----------|
| Code Review | At least 1 approval |
| Build | No errors |
| Tests | All acceptance criteria pass |
